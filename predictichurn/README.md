# 📉 PredictiChurn

> End-to-end Machine Learning pipeline for SaaS/Telecom **Customer Churn Prediction**.  
> XGBoost · SHAP · FastAPI · Streamlit

---

## 🗂️ Project Structure

```
predictichurn/
├── data/                          # Raw CSV + generated charts
├── notebooks/
│   └── PredictiChurn_Training.ipynb   # Phases 2-4: training pipeline
├── backend/
│   ├── main.py                    # FastAPI app (Phase 5)
│   ├── model.pkl                  # Generated by notebook
│   └── preprocessor.pkl           # Generated by notebook
├── frontend/
│   └── app.py                     # Streamlit dashboard (Phase 6)
└── requirements.txt
```

## 🚀 Quick Start

### 1. Install dependencies
```bash
cd predictichurn
pip install -r requirements.txt
```

### 2. Get the dataset
Download **Telco Customer Churn** from Kaggle:  
https://www.kaggle.com/datasets/blastchar/telco-customer-churn  
Place `WA_Fn-UseC_-Telco-Customer-Churn.csv` inside `data/`.

### 3. Train the model (run the notebook)
```bash
jupyter notebook notebooks/PredictiChurn_Training.ipynb
```
This will:
- Clean & preprocess the data
- Apply SMOTE balancing
- Train XGBoost
- Generate SHAP plots in `data/`
- Save `backend/model.pkl` and `backend/preprocessor.pkl`

### 4. Start the API
```bash
uvicorn backend.main:app --reload
```
API docs available at: http://localhost:8000/docs

### 5. Launch the dashboard
```bash
streamlit run frontend/app.py
```
Dashboard at: http://localhost:8501

## 🧠 Technical Architecture

```
User Input (Streamlit)
        │
        ▼  POST /predict (JSON)
  FastAPI Backend
        │
        ├── preprocessor.pkl  →  Scale + OHE encode
        │
        ├── model.pkl (XGBoost)  →  churn_probability
        │
        └── SHAP TreeExplainer   →  top-3 factors
        │
        ▼  JSON Response
  Streamlit Dashboard
        │
        ├── Risk Score Gauge  (Red/Amber/Green)
        └── SHAP Factor List
```
